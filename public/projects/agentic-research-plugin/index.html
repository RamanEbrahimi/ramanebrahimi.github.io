Agentic-Research: a multi-agent research plugin for Claude Code

April 2026 · Raman Ebrahimi · GitHub
Overview

An open-source Claude Code plugin, distributed through a personal plugin marketplace, that turns a research workspace into a repeatable pipeline: eight specialized agents, nine slash-command playbooks and eighteen skills covering proof writing, conjecture testing, adversarial proof review, citation management and venue targeting.

Epistemic rigor

A claim-lifecycle vocabulary and an evidence contract block unproven “theorem” language, and human checkpoints are built into the end-to-end pipeline. The self-hosted GPU pipeline above is a local-LLM port of this plugin.

Tools: Claude Code plugin system, subagents, skills, Git.
